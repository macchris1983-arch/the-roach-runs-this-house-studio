# AGENTS.md — rules for AI assistants working in this repo

You are helping produce **The Roach Runs This House**, an original animated comedy for Facebook Reels.

## Hard rules

1. **Never publish or post anything.** The studio stops at an export folder; the owner uploads by hand.
2. **Never spend money.** No paid APIs, subscriptions, credits or services without the owner's explicit permission. Budget is $0.
3. **Never redesign the characters without approval.** The look is defined in `assets/characters/characters.yaml` and `studio/rigs.py`. Changing either changes the rig hash, and QC will flag it against `assets/characters/approved_lock.json`.
4. **Never fake results.** Don't claim a render, test, QC pass or commit happened unless the command actually ran and succeeded. Pipeline status is derived from real files; don't hand-edit `approval.json` or `export.json`.
5. **Original content only.** No copyrighted characters, scripts, songs, samples or watermarked media. All art, music and SFX are generated by code. Any outside asset needs an entry in `assets/LICENSES.yaml`.
6. **No secrets in git.** No API keys, passwords or tokens. Use a local `.env` (git-ignored).
7. **Preserve existing work.** Don't delete or overwrite episodes, voice recordings or exports without checking with the owner.

## How to work

- Episode source of truth: `episodes/season-XX/<id>-<slug>/episode.yaml`.
- After editing an episode: `python -m studio validate <id>` then `python -m studio produce <id>`.
- Before committing code changes: `python -m pytest -q` (and `RUN_SLOW=1 python -m pytest -q -k full_render` for renderer changes).
- Read QC failures in `build/<id>/qc_report.md`; fix the cause, don't loosen checks to make them pass.
- Comedy bar: every episode needs a hook in the first 2 seconds, a distinct premise, a clear punchline and a loopable ending. No generic filler.

## Characters (short form)

- **The Wife**: Black woman, high curly puff, gold hoops, purple heart-print pajamas, pink fuzzy slippers. Sharp, unbothered, runs the house.
- **The Husband**: Black man, short curly hair, full beard, green tee, dark gray joggers, black slides. Overconfident, easily frightened.
- **The Roach**: small reddish-brown anthropomorphic cockroach, expressive eyebrows, mischievous grin. Acts like he owns the house (and pays rent).
