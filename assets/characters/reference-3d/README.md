# The Roach Runs This House — 3D character references (Pixar-style)

Added November 8, 2026. The show's look is moving from 2D to 3D Pixar-style (owner-approved direction). These sheets were generated in Canva from the owner-approved 2D sheets in `../reference/` and the owner's direction. The originals live in Christopher's Canva account (links open for the account owner). The PNGs in this folder are 800px-wide Canva previews; export full-size from Canva if more detail is needed.
